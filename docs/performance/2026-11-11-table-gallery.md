# Table 示例编排与滚动回归

## 展示方式

原页面默认显示两张表，基础选项共用一张工单表，其余功能由底部五个按钮展开。示例数量和能力范围不易发现，展开多个复杂例子也会增加同页布局工作。

现在复用 YueTabs，将分类导航固定在内容滚动区上方。9类分别为基础样式、布局与交互、本地查询、远程查询、树与详情、编辑与校验、日期与时间、合并与加载、重排与列设置。每类有说明，点击直接进入；窄宽度保留横向滚动、方向键和 Home／End 导航。

基础样式显示10个独立的小表：基础、密度、行分隔线、完整边框、斑马纹、自定义单元格、长文本换行、空表格、初次加载、刷新失败。每例只有0或3条记录，源数据和列只准备一次；尺寸控制位于对应卡片的标题区。自定义内容复用Avatar、Tag与Button；空状态与加载复用Table原有能力。加载需要点击开始，默认没有常驻加载动效。

原属性实验场移到 `table/playground.rs`，基础展示在 `table/basic.rs`；复杂查询、树、编辑和加载逻辑沿用原模块。未修改公共组件API或底层滚动算法。

## 生命周期与验证

Tabs只构建当前面板，其他面板不参与布局与输入。普通示例实体首次访问时创建，后续切换保留查询／编辑状态和稳定身份；50k×256高级压力例与手动加载的100k数据在离开分类后释放。每分类单独持有滚动状态，避免展开内容出现在远离入口的页面底部。

Showcase 78项测试通过，10项opt-in测试忽略，严格Clippy all-targets通过。新增真实交互验证：首屏10张表、9个可点击分类、始终只有一个TabPanel、离开高级分类后卸载、重访普通例保持实体、密度调整不改变其他表、760px窄窗口通过End／Home切换并保持可见焦点。原15项表格交互用例继续通过。

## 性能采样合同

对比基准为 `9aabcb3` 的开发优化版；不与此前未优化的GPUI依赖配置比较。保留原预构建EXE与构建记录，新版单独构建、复制。默认Table页内容已经变化，**两版场景不等价**，所以这次只检验展示改造的CPU回归，不将耗时差异当作同工作量加速。

继续使用真实Showcase、1280×800、rem16、reduce motion、80步预热与240个有效滚轮样本。每步±12px，40步下行后反向返回；检查实际控件移动和往返恢复。新版指针放在y=220的内容区，以避开固定导航；旧版轨迹使用原y=110。计时包含dispatch＋draw／clear，effects在计时外排空，不能替代原生GPU与真实手感。

采样器新增显式 `--ui-regression --cases table` 模式：三组ABBA、12进程、2880个有效样本。采样前冻结每组P50／P95回退不超过10%；每个版本内部逐轨迹点quad数量必须一致，跨版记录差异，不要求新旧画面相同。默认采样模式仍要求同工作量且至少改善20%，旧证据保持原合同。
