Descriptions 描述列表YueDescriptions

在详情页里以“名称—内容”成对展示只读信息。首版范围：单列 / 多列、标签在左 / 在上、单项跨列、按容器宽度降列；有边框 / 无边框、三档密度、标签对齐；文字与任意插槽内容；长内容自然换行，可选择截断并显示完整提示。本页先给出结构与规格，再由局部到整体，最后用“列表 + 卡片 + 描述列表”组成一个工单详情页。

组件结构Anatomy

一个描述列表由可选的头部（标题 + 额外操作）和若干“项”组成；每一项是一对标签与内容。内容可以是文字，也可以是徽标、头像、链接、复制按钮等任意插槽。

尺寸规格 由真实渲染测量，非手填

布局与交互规则

布局Layout

列数是“最多几列”，实际列数由容器宽度决定：容器变窄时自动降列，而不是看浏览器视口。拖动虚线框右下角试试；标签位置可以在左或在上。

最多列数标签位置

跨列与行填充Span · Filled

单项可以跨多列；span 超过当前列数时自动收缩；每行放不下的项自动换行，有边框时每行最后一项会补齐整行，不留空格。缩窄容器观察变化。

外观Appearance

有边框 / 无边框、三档密度、标签左对齐 / 右对齐 / 居中、可选冒号与标签宽度。密度对两种外观都生效。

内容与插槽Content · Slots

内容区不限于文字：状态徽标、头像加姓名、链接、带复制按钮的编号、标签组、进度条都可以直接放进去，对齐与行高保持一致。点击复制按钮，图标变为对勾并给出“已复制”提示。

长内容Wrap · Truncate

默认自然换行，连续的长编号也会在边界处断开，不会撑破布局；也可以截断为单行或两行，只有内容真的被截断时，悬停或聚焦才显示完整内容的提示。缩窄容器观察变化。

整体：工单详情List + Card + Descriptions

左侧列表选择工单，右侧卡片里用描述列表展示详情，切换时内容淡入。点“编辑”后，值槽里换成已有的输入框与下拉框，描述列表本身仍只负责展示。
